Sujet :
EduManage Secure
Application web sécurisée de gestion des apprenants, paiements et accès pédagogiques
Idée du projet :
C’est une application métier full-stack qui permet à un centre de formation de :
•	gérer les comptes utilisateurs
•	gérer les rôles et permissions
•	inscrire des apprenants
•	enregistrer des paiements
•	donner accès à des ressources selon le rôle
•	tracer les actions sensibles
•	protéger les données personnelles et financières
Pourquoi ce sujet est bon
Il colle parfaitement à la logique du cours :
•	application métier full-stack
•	authentification sécurisée
•	gestion des rôles
•	chiffrement des données sensibles
•	audit, logs, observabilité
•	conformité réglementaire
Et il s’aligne avec les attentes du module sur les exigences fonctionnelles, l’architecture cible, le plan sécurité, le MVP et le plan projet. Le document de livrables demande bien ces éléments, avec sécurité intégrée dès la conception.
Le support du cours insiste aussi sur CIA, STRIDE, OWASP Top 10, DevSecOps, JWT/OAuth2, sécurité des API et pipeline sécurisé.

Comment intégrer les 3 stages dans ce projet
Stage 1 — DevSecOps & Pipeline
Nous développons l’application et nous sécurisons le processus de développement :
•	dépôt GitHub
•	pipeline CI/CD
•	SAST avec SonarQube
•	scan dépendances avec OWASP Dependency-Check ou Trivy
•	tests automatisés
•	DAST avec OWASP ZAP
Stage 2 — IAM & Secrets
Nous ajoutons la sécurité d’accès :
•	Spring Security
•	JWT
•	rôles : ADMIN / GESTIONNAIRE / FORMATEUR / APPRENANT
•	permissions par endpoint
•	gestion des secrets via variables d’environnement ou Vault si possible
Stage 3 — Infra, Observabilité & Audit
Nous ajoutons la sécurité “production” :
•	NGINX reverse proxy
•	logs d’audit
•	monitoring
•	dashboard simple Grafana/Prometheus si possible
•	mini audit sécurité
•	plan de remédiation
